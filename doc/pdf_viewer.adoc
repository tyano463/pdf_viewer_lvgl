== Summary
This application allows you to view and manage digital music sheets. It supports various file formats and provides intuitive navigation and annotation features.

== [[introduction]]Introduction
Thank you for using *Music Sheet Viewer*. This guide will walk you through installing, using, and troubleshooting the application.

== [[installation]]Installation


=== Installing the App
. Open the App Store / Google Play
. Search for `Music Sheet Viewer`
. Tap "Install"

== [[usage]]How to Use

=== Opening a Score
. Tap the "+" button on the main screen.
. Choose a file from your library or cloud storage.
. The sheet music will appear in the viewer.

image::screenshots/open_score.png[Opening a Score, width=400]

=== Page Navigation
Use swipe gestures or the navigation bar at the bottom to move between pages.

=== Adding Annotations
. Tap the pencil icon.
. Draw directly on the score.
. Tap "Save" to confirm.

== [[file_formats]]Supported File Formats

[cols="1,1"]
|===
| Format | Description

| PDF | Standard sheet music format
| MusicXML | Editable digital notation
| PNG, JPG | Scanned sheet images
|===

== [[troubleshooting]]Troubleshooting

=== The score does not load
* Make sure the file is not corrupted.
* Try reopening the file.

=== Annotations are not saving
* Ensure you tap the "Save" icon after editing.
* Check that you have write permissions in the app settings.
